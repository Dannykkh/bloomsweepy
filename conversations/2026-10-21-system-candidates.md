# 시스템 후보 화면과 v1.8.0

## user-request

사용자는 v1.8.0 정식 공개를 승인한 뒤, 공개 전에 후보 페이지 화면을 확인하고 수정하도록 요청했다. 이어 대상이 폴더 트리가 아니라 “시스템후보 화면”이라고 정정했다. 원래 사용자 턴 시각과 정확한 세션 ID는 제공되지 않았으며 이 기록은 해당 명시적 요청만 정리한다.

## decision

실제 설치된 1.7.0 표시 개발본의 시스템 후보는 inline-size 컨테이너의 intrinsic sizing 때문에 좁은 띠로 무너졌다. 읽기 전용 검사로 재현했고 파일은 선택·삭제하지 않았다. 기존 React 구성과 글래스 토큰은 유지하면서 중첩 workspace/view에 full-width grid 경계를 명시했다. 중복 검사 버튼을 제거하고 행 영역·긴 경로·부분 경고·OS별 문구와 필터를 정리했다. 실행 권한·확인·재검증 정책은 바꾸지 않았다.

브라우저 합성 상태와 실제 설치 검증은 구분한다. 화면·치수·192개 회귀는 통과했으나 새 1.8.0 설치본의 native 화면 확인은 Mac 잠금 해제 후 별도 진행한다. 공유 확인창의 기존 포커스 복귀 결함은 남아 있다. 근거: [검증 기록](../docs/qa/system-candidates-2026-10-21/review.md), `03b644c`.
