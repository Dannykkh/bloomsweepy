검토 결과, 안전한 범위의 Rust 구현이 가능합니다.

- macOS SDK `malloc.h:516-521`에 따르면 `malloc_zone_pressure_relief(NULL, 0)`는 현재 프로세스의 모든 malloc zone에서 반환 가능한 영역을 최대한 `munmap`하고, 실제 반환한 바이트 수를 돌려줍니다. macOS 10.7 이상 공개 API이며 `libSystem`에도 심볼이 있습니다.
- 다른 앱, 압축 메모리, swap, 시스템 캐시는 건드리지 않습니다.
- Swift의 대량 할당 3회와 시스템 메모리 전후 차이를 “확보량”으로 계산하는 방식은 이식하면 안 됩니다.
- 현재 저장소에는 별도 global allocator가 없어 Apple malloc zone을 사용하는 현재 구성과 맞습니다. 향후 jemalloc 같은 allocator를 도입하면 효과가 달라질 수 있습니다.

권장 명령 계약은 다음입니다.

```ts
type AppMemoryCleanupOutcome = "completed" | "busy" | "unsupported";

interface AppMemoryCleanupResponse {
outcome: AppMemoryCleanupOutcome;
platform: string;
measurement: {
allocatorReleasedBytes: number;
currentProcessResidentBeforeBytes: number | null;
currentProcessResidentAfterBytes: number | null;
observedSystemAvailableBeforeBytes: number;
observedSystemAvailableAfterBytes: number;
completedAtUnixMs: number;
} | null;
}
```

중요한 의미 구분:

- `allocatorReleasedBytes`만 API가 직접 보고한 인과적 결과입니다.
- RSS 전후 값은 현재 Tauri 호스트 프로세스 관찰치입니다. WebKit 보조 프로세스까지 합친 “BroomSweepy 전체”가 아닙니다.
- 시스템 available 전후는 다른 앱 활동에도 변하며, macOS용 `sysinfo`는 active/inactive/free/speculative를 포함해 계산합니다. 따라서 “확보한 메모리”로 표시하면 안 됩니다.
- 반환량이 0이어도 실패가 아니라 `completed`입니다. “현재 반환 가능한 앱 메모리가 거의 없습니다”가 적절합니다.

구현 구조:

- 새 파일: `apps/desktop/src-tauri/src/app_memory_cleanup.rs`
- 입력 없는 `clean_app_memory` Tauri 명령
- `spawn_blocking`에서 실행
- `Arc<AppMemoryCleanupState>` 내부 `AtomicBool`
- `compare_exchange(false, true, AcqRel, Acquire)`와 `Drop` 기반 lease로 중복 실행 방지
- 중복 호출은 IPC 오류 대신 `busy`

FFI 형태는 다음이 안전합니다.

```rust
unsafe extern "C" {
fn malloc_zone_pressure_relief(zone: *mut std::ffi::c_void, goal: usize) -> usize;

// SAFETY: Apple 계약상 null zone은 현재 프로세스의 모든 zone,
// goal 0은 최대 pressure relief를 의미합니다.

malloc_zone_pressure_relief(std::ptr::null_mut(), 0)
};
```

맞아요. **‘시스템 성능’ 아래에 CPU와 메모리를 같은 크기의 원형으로 나란히 보여주는 구성이 더 자연스럽습니다.** 지금도 둘 다 측정하지만, CPU만 크게 강조돼서 제목이 CPU에만 붙은 것처럼 보입니다.

CPU의 ‘정리’는 정확한 개념이 아닙니다. CPU 사용률은 일정 시간 동안 얼마나 연산했는지를 나타내므로, 사용률을 낮추려면 연산을 많이 하는 작업을 줄이거나 앱을 종료해야 합니다. 화면 행동도 `CPU 정리`보다 `많이 사용하는 앱 보기`가 맞습니다. [Apple CPU 안내](https://support.apple.com/guide/activity-monitor/view-cpu-activity-actmntr43452/mac)

메모리는 사용이 끝난 영역을 운영체제에 돌려줄 수 있습니다. 다만 **지금 구현한 버튼은 BroomSweepy 자신의 메모리 일부만 반환합니다.** 동작은 다음과 같습니다.

1. BroomSweepy가 사용을 끝냈지만 메모리 관리자가 재사용하려고 보유한 영역을 확인합니다.
2. macOS의 `malloc_zone_pressure_relief`를 호출해 반환 가능한 영역을 돌려줍니다.
3. API가 보고한 반환량을 표시합니다. 반환할 영역이 없으면 0바이트입니다. [현재 구현](/Users/dannysmacair/Documents/git/BroomSweepy/apps/desktop/src-tauri/src/app_memory_cleanup.rs:68)

따라서 컴퓨터 전체 메모리를 확보하려던 기대에 비하면 현재 기능은 상당히 제한적입니다. 앞서 제가 “메모리 정리 기능을 복원했다”고 표현한 건 범위를 충분히 설명하지 못했습니다.
