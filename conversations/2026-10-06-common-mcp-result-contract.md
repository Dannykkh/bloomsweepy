# 내장 채팅과 외부 MCP의 공통 기능·결과 계약

2026-10-06 19:53 KST 기록 · source: codex · 사용자 턴 원본 시각 미제공.

## 현재 요청

사용자는 MCP로 앱 기능을 호출하고 실제 반환 결과를 분석·응답할 수 있으면 된다고
명확히 했다. 채팅 UI도 그 왕복 위에 붙는다는 통찰을 확인한 뒤 “보완하자”라고 요청했다.

## 확인한 사실

이 Codex 채팅에서 기존 외부 MCP status(연결1/오류 없음), 디스크, CPU/RAM,
BroomSweepy 앱 목록 조회가 실제 응답했다. 기능 목록은16KiB 제한에 걸려 전체가
itemsOmitted로 대체됐다. 내장 채팅은 MCP wire가 아니라 strict JSON 요청을 앱이
파싱하는 경로다. 공통 app dispatcher는 공유하지만 파일 작업 공간은 내장 전용이었다.

## 구현 결정과 범위

기존 JSON/MCP 입구는 유지하고 Rust의 typed 파일 작업/엔진을 공통화한다. 기능 발견은
누락 없는 작은 index와 ID별 상세로 분리한다. 외부 파일 작업은 앱 선택 루트·현재 허용
epoch에 묶인 독립 workspace와 비동기 상태를 사용한다. 최종 실행은 기존 main 앱
확인으로만 연결하며 모델 실행·권한 변경·자동 삭제·개인 자료 테스트를 추가하지 않는다.
대기·실패 결과 뒤에는 추가 행동 없는 분석 전용 응답을 한 번 허용한다.
