# 폴더 선택과 읽기 전용 검사 범위

date: 2026-10-05
source: codex
session: 현재 컨텍스트에 세션 UUID·원본 턴 시각 미제공

## 현재 요청

사용자: “폴더검사는 그냥 다 허용해도 되잖아. 옵션에 굳이 넣을필요가 없는거 같은데?”

직전 읽기 전용 진단에서 설정의 ‘검사 허용’이 비활성인 원인은 전역 검사 root가
없기 때문임을 소스와 실행 화면으로 확인했다. 설정 자체에는 선택 동작 없이 허용
스위치만 있어서 중복된 관문으로 보였다.

## 결정

별도 검사 허용 스위치를 Settings·대화 팝업에서 제거한다. 사용자의 앱 폴더 선택이
읽기 전용 범위를 지정한다. 외부 MCP는 정확한 선택 root·현재 설정을 앱에 요청하며
임의 경로를 받을 수 없다. 내부 AI는 기존 세션 root를 사용한다. 폴더 변경 시 기존
외부 범위를 먼저 철회한다. 삭제·앱 제거·문서 공개·시스템 정리 동의를 없애지는 않는다.

CLI 자체 도구 차단은 직전 진단의 별도 미완료 이슈이며 이번 검사 옵션 제거로
해결됐다고 주장하지 않는다.
