## What This Project Already Learned

- 검색량 감소의 핵심은 임베딩보다 정확한 구조 색인입니다.
- CodeMap 완료 판정은 파일 timestamp가 아니라 필수 산출물 존재와 cache/graph 검증으로 봅니다.
- 리뷰나 에이전트 지적은 API 존재와 시그니처를 실제 코드로 확인한 뒤 반영합니다.
- WebView2 그래프 렌더링은 오프라인 embedded resource와 로드 순서가 중요합니다.
