# BroomSweepy v1.8.0

v1.8.0 정식 릴리즈의 기능과 검증 범위입니다. 정식 버전은 모든 플랫폼·계정·OS 설정과 장시간 메모리 검증을 완료했다는 뜻이 아닙니다. v1.7.0 태그와 설치 파일은 보존합니다.

## 이번 버전

- 앱 소유 파일 검색·용량 검사·하위 탐색·정리 후보 트리를 대화와 연결합니다. 큰 폴더를 묻고 같은 측정 결과를 용량지도에서 볼 수 있습니다. LLM의 임의 셸로 파일 작업을 대신하지 않습니다.
- 하단 고정 채팅 입력창, 실제 작업 단계·경과 시간·취소, 실패 답변 복구와 명시적 재시도를 제공합니다. 조회 결과는 해당 대화의 근거로 다루되 아래 알려진 출처 표시 문제는 남아 있습니다.
- CLI·모델·모델별 지원 추론 강도를 선택합니다. Codex, Claude Code, Antigravity, Grok의 카탈로그·설치·로그인·지원 여부를 구분하며 모든 공급자/계정의 실제 응답을 검증한 것은 아닙니다.
- 조회만 / 확인 후 실행 / 전체 접근을 구분합니다. 전체 접근을 직접 켜면 정확히 이름을 지정한 단순 휴지통 요청은 재검증 후 처리할 수 있습니다. 상담·조건부·모호한 대상, 앱 관련 데이터, 프로세스 종료, Docker 정리, OS 설정과 영구 삭제까지 허용하는 권한은 아닙니다.
- 공통 앱 작업 결과 계약을 내장 채팅과 외부 MCP에서 재사용합니다. 내장 채팅의 구조화 JSON과 외부 MCP 통신은 같은 전송 형식이 아니며, 최종 승인·실행 권한은 앱에 남습니다.
- 선택적 변경 파일 검토는 지정 폴더를5·15·30분마다 메타데이터로 비교합니다. 백신·랜섬웨어 탐지, 실시간 전체 디스크 감시, 자동 AI 전송이나 자동 삭제 기능이 아닙니다.
- Mac Finder5개 설정의 조회·로컬 적용·충돌 검사 복원과 변경 기록,7일 이상 DerivedData/30일 이상 DeviceSupport 개발 캐시 후보를 추가합니다. 채팅은 OS 설정 조회만 하며 실제 설정 적용은 로컬 버튼으로만 요청합니다. Apple Intelligence 강제 제거·보호 해제는 제공하지 않습니다.
- Windows에는 탐색기4개/AI 정책6개 저장값 조회와8개 공식 설정 연결을 별도로 제공합니다. 저장값은 실제 기능의 켜짐/꺼짐이 아니며 레지스트리 쓰기·관리자 상승·Defender 변경·시스템 패키지 강제 제거는 없습니다.
- 작업 중심 메뉴·6분류 앱 설정과 Mac 그룹 설정 화면을 적용했습니다. 시스템 후보의 폭 붕괴·중복 검사 버튼을 고치고, 긴 경로·명시적 행 배치·부분 결과 선행 경고·OS별 문구와 필터를 반영했습니다.

## 설치 파일과 서명

- Mac 배포 대상은 Apple Silicon ARM64입니다. Intel Mac용 바이너리는 포함하지 않습니다. 앱과 두 보조 도구의 버전은1.8.0으로 맞춥니다.
- Mac은 ad-hoc 서명이며 Apple 공증을 받은 배포가 아닙니다. 다운로드한 앱에 macOS 보안 경고가 표시될 수 있습니다. 전역 보안 기능을 끄거나 출처를 모르는 앱의 경고를 우회하지 마세요.
- Windows 대상은 x64 MSI/NSIS이며 설치 파일은 코드 서명되지 않습니다. Windows CI의 빌드·구조 검증과 실제 사용자 환경의 설치/GUI/권한/휴지통 검증은 별개입니다.
- 후보 용량과 휴지통 이동량은 실제 확보 공간의 보증이 아닙니다. 개발 캐시는 다시 빌드·다운로드할 수 있고 앱 설정에는 필요한 데이터가 있을 수 있습니다. 운영체제 휴지통 전체 비우기는 별도 영구 삭제입니다.

## 실제 확인한 범위

- 이번 시스템 후보 변경: TypeScript 확인, 프런트엔드192/192, 실제 컴포넌트 회귀8개 포함.12개 렌더 상태에서 전체 폭, 가로 넘침 없음,14px 이상 글자,44px 이상 조작 표적과 행 경계를 계측했습니다. 합성 확인창에서 개발 캐시 추가 확인과 취소 동선을 확인했고 실제 삭제는 하지 않았습니다.
- 버전 인상 전 로컬 개발본: 실제 Codex의 큰 항목·같은 용량지도·이름 검색·성능/앱/Finder 조회, 자체 메모리 확인 실행, 승인한 합성 파일1개 휴지통 이동 및 Mac A 설치 화면을 확인했습니다. 당시 표시 버전1.7.0을 새1.8.0 설치 파일 검사로 바꾸어 부르지 않습니다.
- 새 버전 Rust 검사·ARM64 패키징·배포 파일 무결성과 해당 커밋 CI 결과는 아래 GitHub 릴리즈에 별도로 기록합니다. 위의 버전 인상 전 설치 관찰을 새 패키지 검증으로 대신하지 않습니다. CI 성공은 실제 사용자 환경의 설치·GUI 검증과 구분합니다.

## 남은 문제와 미검증

- 채팅 복귀 시 이전 파일 조회 결과의 출처 표시, 현재 대화 폴더에 문서 본문 공개 범위를 맞추는 사용성 P2가 남아 있습니다. 실제 문서 본문 검색 성공 경로는 미검증입니다.
- 실제 Finder 설정 쓰기/복원, Windows 실기 설치·GUI, 모든 공급자/계정, 장시간 전체 앱/WebView/CLI 메모리 안정성은 미검증입니다. 자원 상한은 전체 프로세스 트리의 OS 하드쿼터가 아닙니다.
- 공유 확인창은 취소 기본 포커스와 Tab 순환·Escape 닫기를 확인했으나, 닫은 뒤 호출 버튼으로 포커스를 돌려주는 접근성 보완이 남아 있습니다. 전체 VoiceOver·테마별 합성 대비·강제 모션 감소를 인증하지 않습니다.
- 앱 전체 용량·설치일·사용자가 선택하는 이름/날짜/용량 정렬은 미구현입니다. 주기 비교를 예약 자동 정리로 표현하지 않습니다.
- 파일 검색·검사·집계는 로컬이지만 AI 공급자에는 제한된 이름·크기·질문·대화와 별도 허용한 경로/본문 문맥이 전송될 수 있습니다. 완전 오프라인·무전송·고정 토큰 절감률을 보장하지 않습니다.
