# BroomSweepy v1.7.0

정식 릴리스입니다. 정식 버전 표기는 아래 미검증 항목까지 검증했다는 뜻이 아닙니다.

## 추가 기능

- 대화형 빈 폴더 재검사·후보 검토·제외·최종 확인·항목별 결과. 일반 파일 이동·이름 변경을 대화로 실행하는 기능은 미지원입니다.
- 용량 지도에서 일반 폴더 전체를 별도 검토 후 OS 휴지통으로 이동합니다. 숨김 파일·프로젝트·앱을 포함한 하위 항목도 함께 이동하므로 실제 경로와 선택 내용을 확인해야 합니다.
- 앱 관리: Mac 본체와 정확한 앱 식별자 기반 캐시·환경설정 정리는 분리합니다. 전용 제거 프로그램을 우선 사용하세요. Windows는 정식 제거 설정 화면을 열며 폴더·레지스트리·AppData를 추측 삭제하지 않습니다.
- 파일·폴더 열기, 위치 표시, 실행형/스크립트/앱 패키지의 실행 차단.
- OS 휴지통 전체 비우기: 다른 앱의 항목도 포함하는 영구 삭제이며 별도 확인이 필요합니다. AI/CLI/MCP에는 제공하지 않습니다.
- Rust/AppKit macOS 메뉴 막대: 10초 CPU·RAM·시스템 디스크 집계, RAM 숫자 표시 저장, 창 숨김/복원/완전 종료. Windows 트레이는 유지합니다.

## 자원·안전 경계

- 제한된 스트리밍 탐색과 메타데이터 예산, SQLite 캐시·임시 저장·DB/WAL·남은 디스크 점검.
- 본체 메모리 512 MiB 초과 또는 시스템 여유 RAM 256 MiB 미만 시 협조적으로 작업 중단. 이 검사는 500ms 간격이며 전체 프로세스 트리의 OS 하드쿼터가 아닙니다.
- PDF·Office 별도 worker의 Rust 할당 예산 128 MiB, 15초 제한. OS 매핑·allocator 오버헤드를 포함한 전체 RSS 상한은 아닙니다. 실패한 재색인은 마지막 완료 색인을 보존합니다.
- 빈 폴더 검토 최대200개, AI 페이지24개, 5분 유효 일회용 확인. 사용자 확인 직전 신원·실제 비어 있음·보호/클라우드/링크를 재검사합니다. 경로 기반 OS 호출과 외부 프로세스 사이의 TOCTOU를 완전히 제거하지는 못합니다.
- 휴지통 비우기는 경고·체크박스·2분 유효 일회용 확인을 사용합니다. 성공 응답은 OS 요청 결과이지 삭제 개수·확보 공간 보증이 아닙니다.

## 검증 결과와 한계

- Apple Silicon 로컬 자동 회귀: Rust273개·프런트43개 통과. 선택적 실제 CLI 진단1개는 제외. fmt, Clippy all-targets -D warnings, TypeScript 확인 통과.
- 기능 개발 빌드에서 앱 목록·안전한 테스트 문서 열기·확인창 취소, 메뉴 막대 설정 저장·재실행·⌘Q 전체 종료를 확인했습니다.
- 실제 Codex와 새 대화형 도구의 종단 흐름, 장시간 전체 앱/WebView/CLI 메모리 안정성은 미검증입니다. 기존 메모리 부족 종료의 정확한 원인도 확정하지 않았습니다.
- 실제 사용자 앱 삭제, 실제 사용자 휴지통 비우기, 모든 OS 권한창·오류·시간 초과 경로는 검증하지 않았습니다.
- 메뉴 막대 아이콘 직접 클릭·팝오버 내부 버튼·키보드 조작은 화면 도구 제약으로 시각 검증하지 못했습니다.
- 앱 전체 용량·설치일·사용자가 선택하는 이름/날짜/용량 정렬은 미구현입니다. 이름·제작사·경로 포함 단어 검색은 지원합니다.
- Windows 빌드·자동 검사·설치 파일 구조는 해당 릴리스 커밋의 CI 결과를 따릅니다. CI 통과는 Windows 실제 GUI 설치·NTFS 실볼륨·Recycle Bin 조작 검증과 다릅니다.
- macOS는 ARM64 ad-hoc 서명, Apple 미공증입니다. Intel Mac 바이너리는 포함하지 않습니다. Windows 설치 프로그램은 코드 서명되지 않습니다.
- README 이미지는 v1.6.0 당시 실제 React 컴포넌트와 합성 데이터로 만든 참고 화면입니다. v1.7.0의 새 메뉴나 네이티브 패널 캡처로 해석하지 마세요.

## AI 데이터 전송

검사·집계·후보 관리는 로컬 Rust가 처리하고, AI에는 제한된 요약·이름·번호·질문·대화 이력을 보냅니다. 새 후보 페이지에 본문·전체 경로를 자동 첨부하지 않지만, 사용자 입력이나 별도 허용한 MCP 검색에는 경로·문맥이 포함될 수 있습니다. 로컬 CLI는 완전 오프라인 보장이 아닙니다. 토큰 절약률은 측정하지 않았습니다.
