# BroomSweepy v1.8.1

2026-10-21, 정식 패치 릴리스입니다. 사용자가 v1.8.1 정식 공개를 승인했습니다. v1.8.0 태그와 설치 파일을 교체하지 않습니다. 아래의 구현·로컬 검사와 정확한 릴리스 커밋의 CI·배포 파일 검사·실제 설치 검증은 구분합니다.

## 수정 사항

- Mac 메뉴바 요약에 상단 말풍선 꼭짓점과 비활성 상태에도 색이 유지되는 메모리·CPU·시스템 디스크 게이지를 복원합니다. macOS26+에서 하나의 Regular 유리 배경에만 alpha0.82를 적용하고 글자·버튼은 불투명하게 유지합니다. 투명도 감소 설정은 열 때 다시 확인하며 OS 설정은 바꾸지 않습니다. 구버전 재질이 동일하게 보인다고 보장하지 않습니다.
- 요약창의 Esc·앱 비활성화·표시 중 바깥 클릭 닫힘 처리를 보강했습니다. 표시 중 마우스 monitor는 닫을 때 해제하고 늦은 콜백은 세대로 격리합니다. 전역 콜백에서 키·좌표·앱 정보·이력을 읽거나 저장하지 않습니다.
- 영어 전환 후 한국어로 남던 앱 보호 사유, Mac/Windows 설정 경고, 정리 근거, 검색 색인 문제, 앱 도구·MCP/CLI/Docker 설명 등 앱 소유 문구를 현지화합니다. 한국어·영어·일본어·중국어 간 전환을 지원합니다.
- 동적 알림은 번역된 문자열 대신 key+params로 보관해 현재 언어로 표시합니다. 언어를 바꿔도 초기 조회·검사·CLI·리스너·폴링을 다시 시작하지 않습니다. 사용자 이름·경로·문서·기존 대화·모델 자유 응답과 macOS 자체 앱/프로세스 이름은 원문을 유지합니다.
- 본체·MCP·문서 helper·Cargo/package lock·Tauri 창 제목·HTML 문서 제목·MCP 초기 응답 버전을1.8.1로 맞추고 정합성 회귀검사를 추가합니다. 기존 HTML 제목의1.7.0 잔존도 수정합니다.

## 설치 파일과 게시 절차

- Mac: Apple Silicon ARM64 DMG, ad-hoc 서명이며 Apple 공증은 없습니다. Intel 배포는 제공하지 않습니다.
- Windows: x64 MSI/NSIS, 코드 서명되지 않은 설치 파일입니다.
- 동일 릴리스 커밋의 Mac/Windows CI가 성공한 뒤 해당 커밋에 새 태그를 붙이고 검증한 DMG/MSI/EXE와 SHA256SUMS.txt를 게시합니다. 태그만 푸시해 자동으로 빌드·게시되는 구성은 아닙니다.
- v1.8.1은2026-10-21 17:00:51KST에 정식/latest로 공개했습니다. 테스트한 커밋`96e1202b43ea36f3364c23d306e6ea84fe44ff5a`에 태그를 고정했고, 양쪽 CI 성공·원본 ZIP 해시·게시 파일4개 digest를 확인했습니다. 이 Mac 설치 교체와 실행도 완료했습니다. [릴리스·설치 검증 기록](../qa/release-1.8.1-verification.md)

## 검증과 경계

- 버전 인상 전 로컬 수정본(표시1.8.0): frontend216/216, 실제 Provider4언어 전환과 기존 알림 갱신·원문 보존 검사, native 소스 컴포넌트12/12, release-library Clippy, TypeScript/프런트엔드/결합 production build 및 서명 검증 통과. 사용자가 실제 네이티브 재질 미리보기를 승인했습니다.
- 버전 인상 후 정확한 릴리스 커밋의 Mac/Windows CI에서 각각 frontend218/218와 Rust/패키지 검사를 통과했습니다. 검증한 DMG로 이 Mac 앱을 교체했고 정상 종료 상태의 대화·권한·개발 도구 DB3개를 보존했습니다. 실제1.8.1 실행, 기존 영어/시작프로그램/메모리 표시 설정 유지, 영어 Mac 경고·앱 보호 사유, 말풍선 컬러 게이지·Esc·메인 복귀, MCP 초기 버전1.8.1/도구12개를 확인했습니다.
- 최종 설치본의 직접 상태아이콘·물리적 바깥 클릭·실제 desktop 유리 합성은 별도 확인이 필요합니다. 미리보기 승인과 창 단독 캡처는 이를 대신하지 않습니다.
- 실제 Windows 설치/GUI, 구버전 macOS, 일본어·중국어 실화면, 장시간 전체 앱/WebView/CLI 메모리 검증은 별도입니다.
- 미등록 내부/OS/CLI 오류 원문은 보존합니다. 문서 snippet이나 모델 응답과 같은 필드에 담긴 앱 생성 대체 문구도 출처를 구분하지 않고 일괄 치환하지 않습니다. 모든 희귀 오류 분기의 완전 번역을 보장하지 않습니다.
- 파일·삭제·권한·확인 정책은 바꾸지 않습니다. v1.8.0의 문서 본문 공개·채팅 결과 출처·확인창 포커스 복귀 등 기존 검증 한계는 이 패치로 해결됐다고 표시하지 않습니다.
