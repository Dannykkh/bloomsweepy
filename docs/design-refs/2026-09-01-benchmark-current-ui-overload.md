- 소스: `.termsnap/snapshots/clipboard_20260901_125038_563.png`, `.termsnap/snapshots/clipboard_20260901_125103_511.png`
- 캡처일: 2026-09-01
- 모드: 영감 각색
- 적용 대상: Tauri 용량 관리, 빠른 파일 찾기, 로컬 CLI 연결 화면
- 모바일 증거: unavailable. 실제 최소 데스크톱 창 760×600을 별도 검증한다.

## 관찰

| 영역 | 관찰 | 작동하지 않는 이유 | 적용 |
|---|---|---|---|
| 첫 화면 | 안전 상태, 채팅 CLI, 검색 권한, 검사 권한, 드라이브 14개 범주가 연속 등장 | 핵심 질문인 “어디를 검사할까?”보다 선택 기능과 기술 상태가 먼저 읽힌다 | 기본 흐름에서 AI/CLI 제거 |
| 메뉴 | 큰 파일·중복·정리 후보가 독립 최상위 메뉴 | 같은 검사 결과를 공유한다는 관계와 선행 조건이 보이지 않는다 | `용량 관리` 아래 탭으로 그룹화 |
| 트리맵 | 구현됐지만 대시보드 아래쪽에 위치 | 긴 상태판과 드라이브 범주가 먼저 공간을 차지한다 | 용량 관리 첫 작업면으로 승격 |
| 검색 포커스 | 입력 셸 테두리 밖에 강한 파란 링이 한 겹 더 생김 | 단층 패널 원칙과 충돌하고 입력보다 포커스 장식이 강하다 | 내부 2px 포커스로 단순화 |

## Adopt

- 왼쪽 전역 내비게이션, 현재 경로 표시, 14px 최소 글자, 로컬 전용 검색 근거는 유지한다.
- 트리맵의 면적 비교와 폴더 드릴다운을 용량 관리의 주 작업으로 사용한다.

## Adapt

- macOS의 `공간` 범주와 하위 탭 구조를 Tauri의 `용량 관리`와 4개 하위 작업으로 번역한다.
- CLI 상태판은 대시보드 카드가 아니라 선택 기능 전용 화면으로 옮긴다.
- 전체 드라이브 종류별 분류는 초보 흐름 뒤의 선택 상세로 접는다.

## Avoid

- 앱 안에 실제 공급자 연결이 없는 상태에서 채팅 입력창을 그려 내장 AI처럼 보이게 하지 않는다.
- 준비되지 않은 기능을 비활성 버튼만으로 표시하지 않는다. 이유와 다음 행동을 함께 쓴다.
- 큰 카드와 권한 블록을 첫 화면에 연속 배치하지 않는다.
