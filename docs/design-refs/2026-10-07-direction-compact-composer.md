# Direction: reference-led compact input

Selection Quote: “두번째 이미지처럼 만들어줄순 없겠니? 코덱스처럼?”
MODE: Agent Workbench. COMPOSITION: 전체폭 초안→compact footer→위쪽 popup.
MESSAGE: 선택된 모델과 강도가 실제 상태. CTA: 원형 위 화살표/취소.
VISUAL SYSTEM: 기존 neutral glass/Pretendard/14px floor, violet track 한 곳.
STATE: 공급자별 실제 지원 증거·기본값·stale·busy·저장 오류 유지.
RESPONSIVE: container clamp/모델 라벨 압축. MOTION: open opacity/transform≤120ms, reduced-motion없음.
NEGATIVE: 마이크·새 브랜드·큰 select/상시 설명·고정 Ultra/무한 애니메이션.
SUCCESS: 입력 높이 압축·지원 단계 선택·키보드/좁은 pane·오발송0·Settings 공유.

Follow-up Quote: “그 아래쪽 설명자체를 빼지?” 정상 상태의 설명은 팝업으로 이전하지 않고
제거한다. 오류·미지원·기본값 복구 안내만 해당 상태에서 노출한다.
Provider Extension: Claude Code/Grok/Agy도 같은 시각 위계를 사용하되 각 CLI의 실제 모델
목록/지원 단계로 채운다. 모델/강도 저장은 기존 hook, Settings는 기존 Picker를 재사용한다.
이는 사용자 요청의 기능 범위 추가이며 별도의 앱 전체 재디자인이 아니다.

3후보 렌더 exemption: 첨부된 명확한 한 방향을 선택한 작은 입력부 delta. 전체 앱 구조/브랜드를 바꾸지 않는다.
초기 구현 렌더를 보고 구도/비례를 비평하고 필요한 변수1–2개만 수정한다.
별도 recipe 대신 기존 DESIGN.md에서 유도; 새 palette/font/scaffold 없음.
