# Brief: 선택형 Docker 용량 관리

## 무엇을 만드는가

- 설정에서 사용자가 직접 켜는 Docker 용량 분석과 제한된 정리 기능.
- 대화에서 AI CLI는 Docker 사용량을 설명하고 정리를 제안하며, 실제 실행은 BroomSweepy 확인창과 허용 명령 경계가 담당한다.

## 사용자와 과업

- Docker를 쓰는 개발자는 이미지·컨테이너·볼륨·빌드 캐시가 차지한 용량과 정리 가능량을 확인한다.
- 일반 사용자는 기본값이 꺼져 있어 Docker 검사, CLI 실행, 대시보드 항목을 보지 않는다.

## 신뢰와 안전 제약

- `Docker.raw`, `docker_data.vhdx`, `ext4.vhdx` 같은 Docker Desktop 저장 파일을 직접 삭제하거나 수정하지 않는다.
- 앱은 셸 문자열을 실행하지 않고 검증된 `docker` 실행 파일에 고정된 인자만 전달한다.
- 볼륨은 데이터베이스 등 사용자 데이터가 들어 있을 수 있어 사용량만 표시하고 정리 기능에서는 제외한다.
- Docker prune은 운영체제 휴지통을 거치지 않으므로 최종 확인에서 복구 불가능성을 평문으로 표시한다.

## 완료 조건

- 기본 비활성 설정이 재시작 후에도 유지된다.
- 비활성 상태에서는 Docker CLI를 탐색하거나 실행하지 않는다.
- 활성 상태에서 설치 안 됨, 데몬 중지, 사용량 조회 성공, 조회 실패가 구분된다.
- 대화의 Docker 질문에는 앱이 조회한 제한된 요약만 추가되며 AI가 실행했다고 주장하지 않는다.
- 정리는 일회성 미리보기 번호, 허용 범주, 사용자 확인, 실행 후 재조회 순서로만 가능하다.
