## Wide Desktop — 1280×820

```text
+--------------------+-------------------------------------------------------+
| Brand              | 용량 관리 / 폴더 용량 지도             [현재 폴더] |
|                    +-------------------------------------------------------+
| 용량 관리          | [용량 지도][큰 파일][중복 파일][정리 후보]          |
| 파일 이름 찾기     +-------------------------------------------------------+
| 문서 내용 찾기     | 처음이라면 여기부터                                  |
| AI 도우미          | 폴더 선택 → 용량 지도 → 큰 파일·중복      [다음]   |
| 설정               +-------------------------------------------------------+
|                    | 폴더 용량 지도                                        |
|                    | +-----------------------------+---------------------+ |
|                    | | 비례 사각형 지도            | 용량 순위           | |
| disk status        | +-----------------------------+---------------------+ |
+--------------------+-------------------------------------------------------+
```

- 후보 A의 guide-first map을 선택한다.
- 지도 헤더는 기본 1280×820 첫 뷰포트에 들어오며, 검사 결과가 있으면 주요 사각형도 보인다.
- 전체 드라이브 종류별 분류는 지도와 결과 이동 뒤 `details`로 둔다.

## Compact Desktop — 760×600

```text
+------+-----------------------------------------------+
| rail | 폴더 용량 지도                  [현재 폴더] |
|      | [지도][큰 파일][중복][정리 후보]             |
|      | 처음이라면 여기부터                          |
|      | 1 폴더 선택                                  |
|      | 2 용량 지도                                  |
|      | 3 큰 파일·중복                              |
|      | [현재 단계의 다음 행동]                     |
|      | 폴더 용량 지도                               |
|      | 비례 사각형 지도                             |
|      | 용량 순위                                    |
+------+-----------------------------------------------+
```

- 글자를 축소하지 않고 안내 단계를 세로로 재배치한다.
- 지도와 순위는 지도 먼저, 순위 다음 순서로 바뀐다.
- AI 도우미는 전역 내비의 별도 화면이며 기본 용량 관리 흐름에 렌더하지 않는다.

## State Placement

| State | Placement | Next action |
|---|---|---|
| 폴더 없음 | 시작 안내와 지도 빈 상태 | 폴더 선택 |
| 지도 없음 | 시작 안내의 두 번째 단계 | 폴더 용량 지도 만들기 |
| 지도 완료·정밀 검사 없음 | 시작 안내의 세 번째 단계 | 큰 파일·중복 찾기 |
| 정밀 검사 완료 | 결과 이동 행 | 큰 파일·중복 파일 보기 |
| 로컬 CLI 없음 | AI 도우미 연결 상태 | 연결 없이 계속 사용 또는 등록 문서 확인 |
