## 관찰

| 영역 | 현재 문제 | 가져올 구조 | 피할 것 |
|---|---|---|---|
| AI 도우미 | 연결 설명, 3단계, 권한 패널, 기능 경계가 대화보다 먼저 나온다 | 폴더 문맥을 상단 한 줄에 고정하고 대화 기록과 입력을 주 작업면으로 둔다 | 공급자 없이 동작하는 가짜 입력, 권한 설명 카드의 연속 배치 |
| 용량 관리 | 폴더 바꾸기와 지도 만들기가 별도 결정이라 다음 행동이 모호하다 | 폴더 선택을 지도 생성의 시작으로 합친다 | 같은 의미의 primary 행동 두 개 |
| 앱 첫 화면 | 한 폴더 검사만 보여 컴퓨터 전체 상태와 최근 변화가 보이지 않는다 | 드라이브별 사용량, 최근 정리, 최근 새 파일을 별도 대시보드에 둔다 | 모든 지표를 둥근 KPI 카드로 분해 |
| 파일 변화 | 수정 시각은 있지만 “이전 목록 이후 새로 본 파일” 개념이 없다 | 첫 목록은 기준점, 이후 새 경로만 최근 추가로 기록한다 | 첫 색인의 모든 파일을 새 파일로 오인 |

## Adopt

- Codex처럼 폴더를 먼저 고르고 그 범위를 작업 문맥으로 계속 표시한다.
- 데이터 도구의 `현재값 → 최근 변화 → 상세 진입` 순서를 대시보드에 적용한다.

## Adapt

- 코드 프로젝트 대신 일반 폴더를 문맥으로 사용한다.
- 공급자는 판단과 요약만 맡고, 파일 순회·해시·휴지통 이동은 BroomSweepy가 실행한다.
- 최근 파일은 운영체제 생성일이 아니라 BroomSweepy의 이전 파일 목록과 비교한 최초 발견 시각으로 정의한다.

## Avoid

- 설명을 읽어야만 입력창을 쓸 수 있는 온보딩 벽.
- 사용자가 선택하지 않은 폴더를 공급자에게 전달하는 동작.
- 대시보드에서 파일 경로 전체를 필요 이상으로 노출하는 것.
