# Layout Blueprint — 변경 파일 검토

기존 Data Instrument/Settings 방향의 국소 확장. 토큰은 DESIGN.md 그대로 사용.

| 순서 | 블록 | anatomy | 좁은 창 |
|---|---|---|---|
|1|heading/toggle|제목, 한계, 켜짐 상태|toggle 별도 행|
|2|scope|선택 경로, 폴더 선택, 주기|경로 줄바꿈, 버튼 다음 행|
|3|status|단계, baseline 수, 마지막 시각, 실제 오류|세로 flow|
|4|review list|상태 필터, 결과 수,20행 페이지|이름/경로/사유/행동 순|

                                     이전/다음
