# Layout Blueprint — Composer CLI delta

Agent Workbench, medium density, 장식 효과0. 기존 DESIGN.md compact composer와
2026-10-08-experience-composer-provider.md를 따른다. 사용자가 두 진입점의 역할 변경을 명시했다.

| Block | Anatomy | Delta |
|---|---|---|
| Header | 대상·권한·연결 상태·재확인 | 공급자 select만 제거 |
| Composer | 전체폭 textarea·두 trigger·44pxsend/cancel | CLI / 모델·강도 역할 분리 |
| Popup | heading·선택 list/range·복구 | CLI popup 추가, 모델은 통합 popup 부제로 진입 |

```text
| 질문 초안                                         |
| [Codex ▾] [모델 이름 · 중간 ▾]              [↑] |
```

모바일에서는 모델 이름만 우선 압축하며 CLI·강도·전송을 식별 가능하게 유지한다.
popup은 기존 컨테이너폭을 벗어나지 않는다. palette/font/material/상태 스타일을 변경하지 않는다.
