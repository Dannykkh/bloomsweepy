# Direction — Composer CLI delta

승인된 compact-composer의 국소 변경. 새 후보3개 렌더는 생략: 기존 색·폰트·재질·배치 보존,
사용자가 앞쪽 trigger의 역할을 CLI 선택으로 정확히 지정했다.
MODE: Agent Workbench. COMPOSITION: CLI→모델/강도→send. MESSAGE: 실행 주체와 모델 구분.
CTA: 기존 send/cancel. TRUST: 실제 catalog/선호/stale 경계 유지. RESPONSIVE: 모델 라벨 압축.
STATE: 기존 상태/잠금 보존. VISUAL SYSTEM: DESIGN.md. MOTION: 기존100ms opacity popup,
reduced-motion 무모션. NEGATIVE: 중복 모델 버튼/새 설명/임의 모델/권한 확대.
SUCCESS: 공급자별 복원·목록 갱신·키보드·390px.
Selection Quote: "앞쪽에걸, 코덱스, 클로드코드, agy, grok등으로 변경가능하게"
렌더/검증 증거는 후속 critique 문서에 기록한다. 아직 캡처/동작 검증 전.
