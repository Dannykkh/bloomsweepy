# Brief: 상태를 먼저 보여주는 대시보드와 폴더 중심 대화

## 사용자 문제

- 앱을 열어도 어느 드라이브가 찼고 최근 무엇이 달라졌는지 바로 알 수 없다.
- 용량 화면에서 폴더 선택과 지도 만들기가 분리되어 같은 결정을 두 번 하는 것처럼 보인다.
- AI 화면은 실제 대화보다 연결 설명과 권한 블록이 커서 무엇을 입력해야 하는지 알기 어렵다.
- 최근 정리 기록과 이전 목록 이후 새로 생긴 파일을 한곳에서 확인할 수 없다.

## 목표

1. 첫 화면 5초 안에 드라이브별 사용량과 여유 공간을 비교한다.
2. 최근 휴지통 이동과 새로 발견한 파일을 경로 노출을 절제한 목록으로 확인한다.
3. 용량 관리에서 폴더를 선택하면 바로 저장공간 트리맵을 만든다.
4. 대화 화면은 선택 폴더, 대화 기록, 입력창만 기본 노출하고 연결·권한은 접힌 상세로 둔다.
5. 로컬 Codex가 있으면 앱이 만든 검사 결과를 요약하되 실제 파일 I/O는 앱이 수행한다.

## 범위

- Tauri React 내비게이션과 새 Dashboard 화면.
- 파일 카탈로그의 최초 발견 시각·세대와 최근 파일 조회.
- 휴지통 작업 저널의 경로 없는 최근 작업 요약 조회.
- 용량 관리 폴더 선택 후 자동 지도 생성.
- 설치된 Codex CLI를 읽기 전용·임시 세션으로 호출하는 실제 대화 요약 흐름.

## 제외

- 공급자에게 휴지통 이동·레지스트리 변경 명령 공개.
- 백그라운드에서 사용자 동의 없이 전체 드라이브 파일 목록 생성.
- 파일 내용이나 전체 절대 경로를 공급자에게 무조건 전송.
- macOS SwiftUI 앱의 화면 재설계.

## 성공 조건

- 대시보드는 실제 `SystemOverview`의 모든 드라이브를 행 단위로 표시한다.
- 첫 파일 목록은 기준점으로 표시하고, 두 번째 갱신부터 새 파일이 나타난다.
- 최근 정리는 완료 시각·이동 수·논리 용량·완료 상태만 보여준다.
- 새 폴더 선택 한 번으로 지도 검사가 시작된다.
- 대화 입력은 실제 로컬 Codex 응답을 반환하거나 설치·로그인 오류를 입력 바로 옆에 설명한다.
- 1280×820과 760×600에서 가로 넘침 없이 키보드로 모든 핵심 행동에 접근한다.
