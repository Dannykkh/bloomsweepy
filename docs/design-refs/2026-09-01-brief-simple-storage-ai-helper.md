# Brief: 쉬운 용량 관리와 AI 도우미 분리

## 사용자 문제

- 첫 화면에서 로컬 CLI 연결·검색 허용·검사 허용이 저장공간 관리보다 먼저 보여 기본 사용법을 파악하기 어렵다.
- `대시보드`, `공간 정리`, `중복 파일`, `정리 후보`가 각각 다른 메뉴라 하나의 용량 관리 흐름이라는 관계가 보이지 않는다.
- 기존 macOS의 저장공간 트리맵 기능은 Tauri에도 구현돼 있지만 긴 대시보드 아래에 있어 발견하기 어렵다.
- 빠른 파일 찾기 입력은 컨테이너 보더와 강한 외곽 포커스가 겹쳐 선택 상태가 과하다.

## 목표

1. 기본 화면에서 `폴더 선택 → 폴더 용량 지도 → 큰 파일·중복 검사` 순서를 5초 안에 이해한다.
2. 용량 지도, 큰 파일, 중복 파일, 정리 후보를 하나의 `용량 관리` 범주로 묶는다.
3. AI/CLI 제어는 별도 `AI 도우미` 화면으로 옮기고 자동 연결이나 내장 채팅으로 오해하지 않게 한다.
4. 기존 기능·안전 경계·14px 최소 글자·단층 글래스 방향은 보존한다.

## 범위

- Tauri React 앱의 정보 구조, 메뉴 문구, 대시보드 구성, 포커스 표현.
- Rust 검사·검색·휴지통 처리 계약은 변경하지 않는다.
- 앱 내 공급자 채팅창은 만들지 않는다. 현재 구현은 로컬 MCP 연결 상태와 권한만 관리한다.

## 성공 조건

- 1280×820 첫 화면에서 폴더 선택 행동과 `폴더 용량 지도`가 보인다.
- 760×600에서 메뉴와 모든 핵심 행동이 세로 스크롤로 접근 가능하고 가로 넘침이 없다.
- AI 도우미를 열지 않아도 검사·검색·정리를 모두 사용할 수 있다.
- 입력 포커스는 키보드로 명확하지만 이중 외곽선으로 보이지 않는다.
