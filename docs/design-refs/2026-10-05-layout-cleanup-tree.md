# Cleanup tree layout

Direction: extend existing Data Instrument glass, no new palette/card grid or hero.

- Existing storage navigation is above the page, in normal flow.
- Mode tabs and source CTA form a wrapping toolbar. Folder tree and system cleanup keep separate state/policy.
- A single continuous list makes hierarchy and selection the dominant visual information. A bounded disclosure/checkbox gutter precedes names; secondary paths/status are quieter, size aligns at the end.
- Summary and review action follow the tree, without covering the last rows in a short window.
- 1280×820: roomy hierarchy and full scope path. 760×600: wrapping toolbar/path, compressed indentation and scrollable list, no horizontal overflow. Smaller browser fixture width is a stress test, not mobile-app support.
- Real content checks: long names/paths, unknown size, unreadable/truncated branches, protected row, mixed parent, empty source, expired plan, actual result.
- Motion: native disclosure state change and existing short feedback; no sweeping card animation for a destructive selection task. Reduced motion removes nonessential transitions.
