## 앱 설명

Mac 용량이 꽉 찼는데 뭐가 큰지 모르겠어서 만들었습니다.
CleanMyMac에 $40/년 내기 싫은 분들을 위한 Mac 클리너.

▸ 원클릭 스마트 정리
안전한 파일만 자동 선택, 파일 하나하나 확인 가능.
뭘 지우는지 몰라서 불안한 분들도 안심하세요.

▸ 데일리 브리핑
"좋은 아침이에요. Mac 건강 82점, 캐시 3GB 쌓여있어요."
매일 Mac 상태를 알려주는 똑똑한 비서.

▸ 저장공간 맵
어떤 폴더가 얼마나 큰지 한눈에 보여드립니다.
클릭해서 탐색, 우클릭으로 바로 삭제.

▸ 메뉴바 상주
창 닫아도 메뉴바에서 메모리·CPU·디스크 실시간 확인.
CPU 0%, 가벼워서 Mac이 느려지지 않습니다.

▸ 포함된 기능
- 캐시/임시파일 정리
- 대용량 파일 탐색
- 중복 파일 제거
- 메모리 최적화
- 시작프로그램 관리
- 실행 중인 앱 관리
- 악성코드 탐지
- 브라우저 개인정보 정리
- 파일 자동 정리 + 규칙 빌더
- 앱 완전 삭제 (찌꺼기 포함)

▸ 안전 설계
- 모든 삭제는 휴지통으로 이동 (복구 가능)
- 시스템 파일/라이브러리 자동 제외
- 예외 폴더 직접 지정 가능

$4.99 한 번이면 끝. 구독 없음. 광고 없음.
