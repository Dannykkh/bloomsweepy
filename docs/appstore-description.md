## 앱 설명

Mac 용량이 꽉 찼는데 뭐가 큰지 모르겠어서 만들었습니다.
CleanMyMac에 $40/년 내기 싫은 분들을 위한 Mac 클리너.

▸ 원클릭 스마트 정리
안전한 파일만 자동 선택, 파일 하나하나 확인 가능.
뭘 지우는지 몰라서 불안한 분들도 안심하세요.

▸ 정리 알림
사용자가 켠 주기에 맞춰 정리할 시점을 알려드립니다.
검사 완료 알림을 누르면 BroomSweepy 창으로 돌아옵니다.

▸ 저장공간 맵
어떤 폴더가 얼마나 큰지 한눈에 보여드립니다.
클릭해서 탐색하고, 최종 확인 뒤 휴지통으로 이동합니다.

▸ 메뉴바 상주
창 닫아도 메뉴바에서 메모리·CPU·디스크 실시간 확인.
10초 간격으로 상태를 갱신하며 창을 닫아도 메뉴바에서 확인할 수 있습니다.

▸ 포함된 기능
- 캐시/임시파일 정리
- 대용량 파일 탐색
- 중복 파일 제거
- 메모리 최적화
- 시작프로그램 관리
- 실행 중인 앱 관리
- 이름 패턴 기반 의심 항목 검토
- 브라우저 개인정보 정리
- 파일 정리 규칙 저장
- 앱 본체 휴지통 이동 + 관련 파일 검토

▸ 안전 설계
- 자동 이동을 지원하는 항목은 휴지통으로 이동
- 실행 직전 파일 종류와 동일성 재확인
- 소유권을 확정할 수 없는 항목은 Finder 검토 전용
- 예외 폴더 직접 지정 가능

이름 패턴 검토는 전문 보안 제품의 악성코드 검사를 대체하지 않습니다.

$4.99 한 번이면 끝. 구독 없음. 광고 없음.
