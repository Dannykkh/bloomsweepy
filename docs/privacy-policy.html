BroomSweepy 개인정보 처리방침

시행일: 2026년 3월 25일 | 최종 수정: 2026년 3월 25일

BroomSweepy는 사용자의 개인정보를 수집, 저장, 전송하지 않습니다.

1. 수집하는 정보

BroomSweepy는 어떠한 개인정보도 수집하지 않습니다.

  • 회원가입이나 로그인이 없습니다.
  • 사용자의 파일 목록, 스캔 결과, 삭제 기록을 외부로 전송하지 않습니다.
  • 분석(Analytics), 광고, 추적 도구를 사용하지 않습니다.

2. 로컬 데이터

다음 데이터는 사용자의 기기에만 저장되며 외부로 전송되지 않습니다:

  • 정리 규칙 설정 — UserDefaults에 저장
  • 폴더 접근 권한 — macOS Security-Scoped Bookmark으로 저장
  • AI 분류 API 키 (선택 사항) — 사용자가 직접 입력한 경우 UserDefaults에 저장. API 호출 시 해당 API 제공자(Anthropic)의 개인정보 처리방침이 적용됩니다.

3. 파일 접근

BroomSweepy는 macOS 앱 샌드박스 환경에서 실행되며, 사용자가 명시적으로 선택한 폴더에만 접근합니다. 파일 스캔 및 정리 작업은 모두 사용자의 기기에서 로컬로 수행됩니다.

4. 네트워크 통신

BroomSweepy는 기본적으로 인터넷 연결을 사용하지 않습니다. AI 파일 분류 기능을 활성화한 경우에만 사용자가 입력한 API 키를 통해 외부 API와 통신합니다.

5. 제3자 제공

사용자의 데이터를 제3자에게 판매, 공유, 제공하지 않습니다.

6. 아동 개인정보

BroomSweepy는 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.
