## Context for Resuming
### Important Context
현재 빌드는 분석 전용이며 삭제 명령은 없다. Windows 레지스트리는 DisplayName, DisplayVersion, Publisher, InstallLocation, EstimatedSize만 조회하며 앱 용량 계산에는 합산하지 않는다. C: 실제 실행에서 8초 내 12,288개 파일의 점진 결과가 표시됐고 취소가 동작했다.

### Potential Gotchas
- Windows의 드라이브 합계는 현재 논리 크기이며 NTFS 실제 할당량과 다를 수 있다.
- 점진 집계 중 수치는 확정값이 아니므로 삭제 추천 입력으로 바로 사용하면 안 된다.
- 작업 트리는 이번 작업 이전부터 대부분 미추적 상태였으므로 정리나 리셋을 하지 않는다.
