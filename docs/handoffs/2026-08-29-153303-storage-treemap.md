## Context for Resuming
### Important Context
코어는 링크를 따라가지 않으며 직계 자식 512개와 빈 폴더 경로 200개를 기본 상한으로 반환한다. UI는 가장 큰 14개와 나머지 합계 `기타`를 합쳐 최대 15개 사각형만 렌더한다. 빈 폴더와 트리맵은 모두 읽기 전용이다.

### Runtime Evidence
- 6MB, 3MB, 512KB 파일이 약 12:6:1 면적 비율로 렌더됐다.
- `beta` 폴더 진입 후 브레드크럼으로 루트 복귀가 확인됐다.
- 엄격한 빈 폴더 2개를 탐지했고 내용이 빈 하위 폴더인 부모는 제외했다.
- 최소 창 너비에서 트리맵과 용량 순위가 세로로 재배치됐다.
- 검증용 임시 데이터와 스크린샷은 Windows 휴지통으로 이동했다.

### Potential Gotchas
- 최초 결과 전에 존재하지 않는 캔버스에는 `ResizeObserver`를 연결할 수 없으므로 결과가 생긴 뒤 관찰을 시작해야 한다.
- Windows 결과 경로에는 `\\?\` 확장 경로 접두사가 나타날 수 있으나 Tauri 왕복에는 유효하다.
- 작업 트리는 이번 작업 이전부터 대부분 미추적 상태였으므로 정리나 리셋을 하지 않는다.
