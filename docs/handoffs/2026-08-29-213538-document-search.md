## Current State Summary
Tauri 앱에 선택 폴더 기반 문서 검색 화면과 공용 Rust 로컬 전문 색인을 추가했다. 일반 텍스트·코드·텍스트 PDF·DOCX·XLSX·PPTX·HWPX를 추출하고 SQLite FTS5 trigram으로 파일명·경로·본문을 검색한다. 수정되지 않은 문서는 재사용하고 색인 갱신은 하나의 트랜잭션으로 처리해 취소·비정상 종료 시 직전 완료 색인을 유지한다. Rust 전체 회귀, Windows 잠금·자원 반복 계측, TypeScript·Vite, 1280×820·760×600 렌더, 릴리스 실행과 MSI·NSIS 패키징을 검증했다.

### Decisions Made
| Decision | Rationale |
|----------|-----------|
| RAG보다 로컬 정확 검색을 먼저 구현 | 파일 스캔 속도와 결정적 검색에는 외부 모델이 필요하지 않고 개인정보 경계가 명확함 |
| SQLite FTS5 trigram과 원문 미리보기 사용 | 한국어 포함 연속 문자열·파일명·경로를 별도 형태소 서버 없이 검색하고 재실행 캐시를 유지할 수 있음 |
| 경로·크기·수정 시각이 같은 문서 재사용 | 매번 본문을 다시 읽지 않으면서 명시적 색인 업데이트 흐름을 단순하게 유지 |
| 색인 전체를 단일 트랜잭션으로 갱신 | 취소·오류·프로세스 종료 뒤 불완전한 세대를 검색 결과로 노출하지 않음 |
| 파일 32 MiB·본문 4 MiB·문서 100,000개 기본 상한 | 전체 드라이브에서도 메모리·DB 성장과 악성 압축 문서 영향을 제한 |
| 추출은 직렬, 순회만 최대 4개 | HDD 탐색 경합과 PDF·압축 해제 메모리 피크를 피함 |
| 구형 HWP·OCR·암호 해제를 명시적으로 제외 | 지원하지 않는 문서를 검색 성공으로 가장하거나 무거운 별도 엔진을 암묵적으로 실행하지 않음 |
| 검색 결과를 삭제 근거와 분리 | 본문 일치는 파일 정리 안전성이나 불필요성의 증거가 아님 |

## Context for Resuming
### Important Context
색인 DB는 Tauri `app_cache_dir()` 아래 `document-search-v1.sqlite3` 하나를 사용하고 마지막 선택 범위만 보존한다. 다른 폴더를 선택하면 UI가 기존 범위 검색을 막고 새 색인을 요구한다. 자동 파일 감시는 아직 없으므로 완료 시각과 `색인 업데이트`가 현재 신선도 계약이다.

검색어 3자 이상은 FTS trigram의 연속 문자열 검색, 1~2자는 `LIKE` 폴백이다. 서버 결과 상한은 250개이고 UI는 100개를 요청한다. 전체 본문은 WebView로 보내지 않고 SQLite의 강조 문맥만 구조화해 반환한다.

검증 결과는 Rust 코어 29개, Windows 자원 테스트 1개, Tauri 19개 통과, 실제 OS 휴지통 테스트 2개 의도적 ignore다. 문서 전용 단위 테스트는 한글·짧은 검색·형식 필터·DOCX·HWPX·PDF·CP949·증분 재사용·취소 롤백·잠금·구형 HWP를 포함한다. Clippy `-D warnings`, TypeScript 검사, Vite 빌드도 통과했다. UI 렌더 증거는 `.termsnap/design-audit/document-search-1280x820-top.png`와 `.termsnap/design-audit/document-search-760x600-top.png`다.

릴리스 실행 파일은 4초 스모크에서 `Responding=True`, private bytes 8,011,776이었다. 번들은 다음과 같다.

- MSI: `target/release/bundle/msi/BroomSweepy_0.1.0_x64_en-US.msi`, 7,548,928 bytes, SHA-256 `B0930AEF4703379A286A2843580408F16E7346B86A1EB07DEF363CA7155E9D58`
- NSIS: `target/release/bundle/nsis/BroomSweepy_0.1.0_x64-setup.exe`, 5,944,762 bytes, SHA-256 `2E09C3564FAE90DA5A97546DD43D0032870009BB3116B0FB2952CDD48CF7A2B6`

### Potential Gotchas
- SQLite에는 추출 본문이 평문으로 저장되므로 로컬 전용이라는 말이 암호화 저장을 뜻하지 않는다.
- FTS 외부 콘텐츠 트리거는 `generation`만 바뀌는 재사용 문서에서는 실행되지 않도록 `UPDATE OF name, path, content`로 제한했다.
- PDF 라이브러리 내부 파싱 중에는 취소 플래그를 확인할 수 없어 한 문서 파싱이 끝난 뒤 취소될 수 있다.
- ZIP 문서는 허용 경로와 압축 해제 크기 상한을 모두 통과한 XML만 읽어야 한다.
- 범위가 100,000개 문서 상한을 넘으면 순회 순서의 일부만 유지하므로 더 작은 폴더를 선택하라는 UI 경고를 보존한다.
- 현재 전체 색인 갱신 트랜잭션 동안 다른 프로세스의 같은 DB 쓰기는 잠길 수 있으며 앱 UI는 공용 작업 잠금으로 동시 실행을 막는다.
- 저장소 기준선 대부분이 아직 untracked이고 `.gitignore`에는 사용자 변경이 있으므로 일괄 정리·리셋하지 않는다.
- 셸 PATH에는 Cargo가 없어 Tauri 패키징 전 `%USERPROFILE%\.cargo\bin`을 명령 범위 PATH에 추가해야 한다.
