# 선택적 변경 파일 검토

기본 OFF인 **주기적 메타데이터 비교**다. 실시간 watcher나 바이러스·랜섬웨어 탐지/방어 엔진이 아니다.
사용자가 설정에서 선택한 폴더 하나에만 적용하고5/15/30분마다 확인하거나 `지금 확인`을 요청한다.

## 입력 → 검사 → 표시

설정은 Rust 앱 데이터의 별도 bounded SQLite에 저장한다. 외부 공개 권한/삭제 승인 DB와 섞지 않는다.
옵션 ON은 AI 공개 허용을 생성하지 않는다. 설정 저장 실패/복원 실패는 그대로 표시한다.
앱을 완전히 종료하면 scheduler도 종료한다. 창을 숨겨 상주하는 것은 완전 종료와 다르다.

처음 완전 검사와 앱 재시작의 첫 검사는 비교 기준이며 기존 파일을 새 파일로 표시하지 않는다.
주기/ON·OFF 변경은 진행 검사를 취소하고 새 비교 기준을 만든다. 폴더 변경·앱 재시작은
기존 기록을 초기화하며 같은 폴더의 주기/OFF 변경은 이전 검토 기록을 유지한다.

코어는 기존 demand-driven DFS와 local-path 검증을 재사용한다. 파일 내용은 읽지 않으며
크기·정밀한 수정시각·종류·파일 신원·실행 속성만 비교한다. 일반 폴더의mtime만 변한 경우는
자식 변경을 중복 보고하지 않는다. 이름 변경은 파일 신원이 이전/현재 각각 하나일 때만
연결하고, hardlink 등 이름 변경이 모호한 경우는 추가·제거로 표현한다.
파일 신원 확인 자체가 실패하면 완전한 비교로 취급하지 않고 검사 미완료로 종료한다.
폴더의 하위 용량 합산은 하지 않으며 UI와 모델 결과에서 미측정으로 표시한다.

알려진 cloud/온라인 전용/reparse/링크는 검사하지 않는다. 이 루틴은 비교 누락으로 잘못된
삭제 기록을 만들지 않도록 제외·읽기 실패·경로/깊이/메모리/시간/개수 상한을 보수적으로
검사 미완료로 처리한다. 완전한 snapshot만 새 기준으로 반영한다. 원격 볼륨/네트워크 경로를
거부하고 하위 mount 경계를 넘지 않는다. 자체 저장 변경을 관찰하지 않도록 앱 데이터
폴더와 겹치는 범위(홈 전체 등)는 거부한다. 더 작은 로컬 폴더를 선택해야 한다.

## 검토와 넘김

- 실행형/스크립트·실행 속성, 문서처럼 보이는 이중 확장자, 한 번의 비교에서50개 이상 변경은 검토 필요 사유다.
- 다른 항목의 자동 넘김은 **선택된 규칙에 해당하지 않음**이며 안전/무해 판정이 아니다.
- 사용자는 항목을 넘기거나 다시 검토할 수 있다. 해당 변경의 상태만 바꾸며 파일은 변경하지 않는다.
- 같은 경로가 다시 바뀌면 새 기록/새 ID로 교체해 이전 수동 넘김을 그대로 재사용하지 않는다.
- 파일 실행·열기·삭제·격리·프로세스 차단·네트워크 차단·AI 자동 호출을 제공하지 않는다.

## 자원 상한

한 검사10,000항목/보관 native 경로4MiB/협력 시간8초, 변경 결과250개/표시 기록1MiB,
UI/MCP 페이지20개. 기존 시스템 자원 가드와 단일 ScanRuntime lease를 사용한다.
검사/정리 작업이 진행 중이면 큐에 누적하지 않고 다음 주기로 이월한다. UI는 상태만5초마다
겹치지 않게 조회하며 화면 해제 시 polling을 정리한다. OFF/폴더 변경/종료는 revision과
협력 취소로 오래된 결과 반영을 차단한다. 한 번의 OS I/O를 강제8초에 중단하는 보장은 아니다.

## AI/MCP 결과

`app_action`의 `{"kind":"file_changes","offset":0,"filter":"all"}` → `files.changes`는
**이미 앱이 만든 검토 목록만 읽는다**. 감시 설정·즉시 검사·넘김·파일 실행/삭제를 할 수 없다.
내장 대화의 선택 루트 또는 외부 앱 선택 검사 루트가 루틴 폴더와 정확히 일치해야 한다.
외부는 현재 scope epoch/권한을 결과 복사 후에도 재검증한다. 모델용 결과는 이름·변경 종류·
규칙 사유·크기·시각·완료/생략 상태만 포함하고 전체/이전 경로·로컬 오류·내부 ID를 뺀다.
LLM 분석을 사용자가 요청하면 이 제한된 metadata가 공급자에게 전달될 수 있다. 루틴 자체는
자동으로 AI 요청이나 파일 내용 전송을 하지 않는다.
검토 설정 revision과 루트도 결과 복사 후 재확인하여 설정이 바뀐 이전 페이지를 전달하지 않는다.

## 한계

주기 사이 생성됐다 사라진 파일, 내용만 바뀌고 크기·수정시각 등이 복원된 파일은 놓칠 수 있다.
metadata가 같다는 이유로 바이러스가 없다고 판단하지 않는다. 알림/일정 자동 정리와 OS 백신
연결은 이번 구현 범위가 아니다. Mac/Windows의 실제 검증 범위는 해당 QA 기록을 따른다.
