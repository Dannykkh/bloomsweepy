# Tauri 데스크톱 UI/UX 감사

## 결과

실제 Windows WebView2 릴리스 빌드를 1280×820과 최소 지원 폭 760px에서 관찰했습니다. 다크 글래스 방향, 기존 파란색·보라색 저장공간 링, 데이터 중심 정보 구조를 유지하면서 접근성과 작은 창 대응을 보완했습니다.

| 영역 | 점수 | 근거 |
|---|---:|---|
| 다크 테마 | 9.2/10 | `color-scheme: dark`, 시맨틱 토큰, 네이티브 옵션 색 지정 |
| 반응형 | 9.0/10 | 1280px와 760px에서 가로 넘침 없음, 컨테이너 쿼리 적용 |
| 접근성 | 9.1/10 | 건너뛰기 링크, 시맨틱 영역, 가시적 포커스, ARIA live, Esc 메뉴 닫기 |
| 로딩과 성능 | 8.7/10 | 단계별 진행률, 취소, 빈 상태, 결과 행 `content-visibility` 적용 |
| 폼 UX | 9.0/10 | 모든 select와 검색 입력에 연결된 레이블, 다크 네이티브 컨트롤 대응 |
| 내비게이션 | 9.0/10 | 현재 화면 강조, 일관된 레일, 작은 창 오버레이와 키보드 닫기 |
| 타이포와 간격 | 9.1/10 | Pretendard와 JetBrains Mono 실제 로드 확인, 수치용 고정폭 체계 |
| 애니메이션 | 9.2/10 | transform과 opacity 중심, reduced-motion 대응 |
| AI Slop 회피 | 8.8/10 | 기능형 데이터 레이아웃, 브랜드 링 외 장식 제한, 카드 반복 최소화 |

가중 총점은 9.0/10, 등급 A입니다.

## 수정한 주요 문제

- 낮은 대비의 보조 텍스트를 AA 기준 이상으로 조정했습니다.
- 작은 창에서 닫힌 사이드바가 키보드 포커스를 받지 않도록 했습니다.
- 메뉴를 Esc로 닫고 `aria-controls`로 관계를 노출했습니다.
- 본문 건너뛰기 링크와 유효한 ISO 날짜 메타데이터를 추가했습니다.
- 취소 완료 상태와 복구 문구를 별도로 표시했습니다.
- 검색 입력에 이름, 자동완성 정책, 맞춤법 정책을 추가했습니다.
- 50개가 넘을 수 있는 결과 행에 지연 렌더링 힌트를 추가했습니다.

## 실제 렌더 증거

초기 대시보드, 큰 파일·중복 요약, 검증된 중복 그룹, 실제 폴더 스캔 화면을 로컬에서 캡처했습니다. 원본 이미지에는 감사용 로컬 테스트 경로가 표시되므로 Git에서는 제외하고 아래 검증 결과만 보존합니다.

## 자동 검증

- 1280×820과 760×600에서 문서 가로 넘침 없음
- 첫 Tab 포커스가 본문 건너뛰기 링크임을 확인
- 390px 감사용 브라우저 하네스에서 메뉴 Enter 열기와 Esc 닫기 확인
- Pretendard Variable과 JetBrains Mono의 `document.fonts.check()` 결과 `true`
- 본문, 보조 텍스트, 기본 버튼의 대표 색상 대비 AA 확인

모바일 390px는 감사용 폴백일 뿐 제품 지원 범위가 아닙니다. Tauri 창의 최소 폭은 760px입니다.
