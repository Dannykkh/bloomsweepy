# BroomSweepy 용어 사전

> 생성일: 2026-08-31
> 도메인: 저장공간 분석과 채팅 CLI 제어
> 버전: v1.2
> 대상: 사용자, 개발자, 채팅 CLI 연결 작업자

## 핵심 용어

### Analysis Engine (분석 엔진)

- **정의**: 파일 크기, 중복, 문서 내용, 정리 후보를 실제로 검사하는 Rust 코드.
- **영문 식별자**: `analysis_engine`, 기존 공개 크레이트는 `bloomsweepy_core` 유지.
- **한글 표기**: 분석 엔진 또는 검사 기능.
- **금지 표현**: 채팅 모델이 파일을 직접 검사한다.

### Chat CLI (채팅 CLI)

- **정의**: Codex, Claude, Gemini처럼 사용자의 자연어 지시를 구조화된 BroomSweepy 기능 호출로 바꾸는 외부 채팅 도구.
- **영문 식별자**: `chat_cli`.
- **한글 표기**: 채팅 CLI.
- **금지 표현**: AI 삭제기, 자동 삭제 봇.

### Control Client (제어 도구)

- **정의**: 채팅 CLI의 요청을 BroomSweepy 앱에 전달하고 결과를 돌려주는 얇은 명령줄 프로그램.
- **영문 식별자**: `control_client`, 실행 파일 후보는 `bloomsweepy-cli`.
- **한글 표기**: 제어 도구.
- **금지 표현**: 독립 정리 엔진.

### Control Bridge (연결 통로)

- **정의**: 현재 사용자만 접근할 수 있도록 채팅 제어 도구와 실행 중인 BroomSweepy 앱을 연결하는 로컬 통신 경로.
- **영문 식별자**: `control_bridge`.
- **한글 표기**: 연결 통로.
- **관련 개념**: MCP, Windows Named Pipe, Unix Domain Socket은 구현 기술명으로만 사용.

### Allowed Root (허용 폴더)

- **정의**: 사용자가 `AI 도우미`에서 이번 앱 실행의 채팅 검색 또는 새 검사 대상으로 명시적으로 허용한 최상위 폴더. 검색 허용과 검사 허용은 서로 대신하지 않으며, 앱을 다시 켜거나 해당 기준이 바뀌면 다시 허용한다.
- **영문 식별자**: `allowed_root`.
- **한글 표기**: 허용 폴더.
- **금지 표현**: 전체 컴퓨터 접근 권한.

### Operation (작업)

- **정의**: 한 번의 검사, 검색, 취소 또는 휴지통 검토 요청. 고유 번호로 구분한다.
- **영문 식별자**: `operation`, `operation_id`.
- **한글 표기**: 작업, 작업 번호.
- **금지 표현**: 세션과 작업을 같은 뜻으로 혼용.

### Scan Generation (검사 번호)

- **정의**: 완료된 검사 결과가 어느 시점의 파일 상태인지 구분하는 번호. 새 검사가 끝나면 바뀐다.
- **영문 식별자**: `scan_generation`.
- **한글 표기**: 검사 번호.
- **금지 표현**: 세대, 스냅샷 버전(사용자 화면).

### Candidate (후보)

- **정의**: 검사 결과상 확인할 가치가 있는 파일 또는 폴더. 후보라는 사실만으로 삭제 승인이 되지는 않는다.
- **영문 식별자**: `candidate`, `candidate_id`.
- **한글 표기**: 정리 후보, 중복 후보.
- **금지 표현**: 삭제 대상(승인 전), 불필요한 파일(근거가 불충분할 때).

### Review Plan (확인 계획)

- **정의**: 어떤 검사 결과에서 어떤 후보를 왜 휴지통으로 옮기려는지 고정한, 짧은 시간만 유효한 목록.
- **영문 식별자**: `review_plan`, `plan_id`, `plan_digest`.
- **한글 표기**: 확인 계획.
- **금지 표현**: 삭제 명령, 자동 실행 계획.

### Final Approval (최종 확인)

- **정의**: BroomSweepy 앱이 정확한 경로, 개수, 용량, 추천 이유를 보여준 뒤 사용자가 앱 안에서 내리는 실행 결정.
- **영문 식별자**: `final_approval`.
- **한글 표기**: 최종 확인.
- **금지 표현**: 모델 승인, CLI 자동 승인.

### Trash Move (휴지통 이동)

- **정의**: 운영체제 휴지통으로 파일이나 폴더를 옮기는 복구 가능한 작업.
- **영문 식별자**: `trash_move`.
- **한글 표기**: 휴지통으로 이동.
- **금지 표현**: 영구 삭제, 완전 삭제.

### Action Journal (작업 기록)

- **정의**: 휴지통 이동 전후 상태를 로컬 디스크에 동기화해 비정상 종료 뒤 확인할 수 있게 하는 기록.
- **영문 식별자**: `action_journal`.
- **한글 표기**: 작업 기록.
- **금지 표현**: 채팅 기록, 클라우드 로그.

## 관계도

```mermaid
flowchart LR
    User[사용자] --> Chat[채팅 CLI]
    Chat --> Client[제어 도구]
    Client --> Bridge[연결 통로]
    Bridge --> App[BroomSweepy 앱]
    App --> Engine[분석 엔진]
    Engine --> Candidate[후보]
    Candidate --> Plan[확인 계획]
    Plan --> Approval[앱의 최종 확인]
    Approval --> Trash[휴지통 이동]
    Trash --> Journal[작업 기록]
```

## 금지 표현 모음

| 금지 | 대신 사용 | 이유 |
|---|---|---|
| AI가 삭제 | 채팅 CLI가 요청, 앱이 확인 후 실행 | 실제 책임 경계를 정확히 표시 |
| 삭제 대상 | 정리 후보 | 후보는 아직 승인되지 않음 |
| 영구 삭제 | 휴지통으로 이동 | 현재 제품은 영구 삭제를 제공하지 않음 |
| provider | 연결 대상 또는 검사 방식 | 사용자 화면에서 뜻이 모호함 |
| broker, DTO, generation | 연결 통로, 전달 형식, 검사 번호 | 사용자 문구를 쉽게 유지 |
