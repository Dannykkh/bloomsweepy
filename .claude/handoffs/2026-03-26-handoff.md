### Liquid Glass 적용 대상
- 사이드바 카테고리 카드
- 대시보드 히어로 링 배경
- 카드/패널 배경 (.ultraThinMaterial → .glassEffect)
- 메뉴바 팝업
- 설정 페이지 섹션

### 코드 패턴
```swift
if #available(macOS 26, *) {
    content.glassEffect(.regular, in: .rect(cornerRadius: 16))
} else {
    content.background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 16))
}
```
