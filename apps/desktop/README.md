# BroomSweepy Desktop

**대화형 파일관리 시스템 BroomSweepy**의 공용 데스크톱 앱입니다. Tauri 2, React 19, TypeScript, Rust를 사용하며, 대화를 주된 조작 방식으로 삼아 검색·검사·후보 검토·최종 확인·실행 결과를 한 흐름으로 연결하는 것을 목표로 개발합니다.

## 제품 방향과 구현 상태

- 목표 구조: AI는 요청 해석과 앱 도구 선택을 맡고, 실제 파일 작업과 대상 재검증은 Rust 앱이 수행합니다. 채팅의 작업 미리보기·최종 확인·결과 표시를 트리맵 및 파일 목록과 연결하고, AI 공급자별 어댑터가 같은 앱 도구를 사용하도록 합니다.
- v1.7.0의 내장 채팅은 빈 폴더 재검사·후보 검토·최종 확인·휴지통 결과를 연결합니다. 일반 파일 이동·이름 변경은 미지원이며, 실제 Codex와 새 도구 흐름의 종단 검증은 남아 있습니다.
- 외부 CLI/MCP 제어와 내장 채팅은 별개입니다. 현재 MCP는 허용된 스캔 요청과 정리 계획 작성 등을 제공하지만, 최종 파일 작업은 앱의 확인을 거칩니다.

제품 소개와 현재 사용 가능한 기능은 [한국어 README](../../README.md)와 [English README](../../README.en.md)를 참고하세요.

### v1.7.0: 대화형 빈 폴더 정리

`assistant_tools.rs`의 공통 JSON 요청은 세션의 폴더 재검사·24개 후보 페이지·후보 선택 수정만 허용합니다. AI는 경로나 셸 명령을 전달하거나 최종 승인·휴지통 이동을 호출할 수 없습니다. 채팅 안의 카드가 최대 200개 후보의 실제 경로를 보여주고, 사용자 선택에 묶인 5분 일회용 계획을 별도 확인 버튼으로 실행합니다. 기존 휴지통 기록·취소·부분 실패 경로를 재사용하며, 비어 있음·신원·보호 경로·클라우드·링크를 재검증합니다. 실제 Codex와 새 도구 흐름의 종단 검증은 남아 있으며 자세한 범위는 릴리스 안내를 참고하세요.

검사와 후보 관리는 로컬이며, AI 입력은 제한된 요약·후보 이름/번호·질문·대화 기록입니다. 파일 본문이나 후보 전체 경로를 자동 첨부하지 않습니다. 사용자 입력이나 별도 MCP 검색에는 경로·본문이 포함될 수 있고, CLI 읽기 전용은 외부 전송 차단이 아닙니다. 토큰 효율은 전달 데이터와 호출 횟수에 달렸으며 절감률은 미측정입니다.

### v1.7.0: 저자원 보호·일반 폴더 이동

현재 소스는 탐색 대기열 대신 제한된 스트리밍 탐색을 사용합니다. 호스트 작업 메모리 512 MiB와 시스템 여유 RAM 256 MiB를 500ms 간격으로 확인하며, SQLite 캐시·DB/WAL·여유 디스크에도 별도 예산을 둡니다. PDF·Office 문서는 128 MiB Rust 할당 예산과 15초 제한을 가진 별도 프로세스에서 처리합니다. 처리 도구나 자원 문제로 실패한 재색인은 이전 완료 색인을 보존합니다. 이는 전체 앱 프로세스 트리의 OS 하드쿼터가 아닙니다.

용량 지도에서 폴더의 **더보기 → 휴지통 이동 검토**를 선택하면 전체 경로·파일/폴더 수·논리 용량을 확인할 수 있습니다. 하위 항목 전체 이동에 체크한 뒤 최종 버튼을 눌러야 실행하며, 계획은 5분 동안 한 번만 사용합니다. 검사 루트·다른 장치·시스템·클라우드·링크 경계는 차단합니다. 일반 폴더 내부의 숨김 파일·앱·프로젝트도 함께 이동하므로 반드시 검토하세요. 영구 삭제나 자동 휴지통 비우기는 하지 않습니다.

정책값·검증 범위·남은 제한은 [v1.7.0 릴리스 안내](../../docs/releases/v1.7.0.md)를 참고하세요. v1.6.1 공개 릴리스에는 이 기능이 없습니다.

### v1.7.0: macOS 메뉴 막대

`src-tauri/src/menu_bar/macos.rs`가 Rust/objc2로 네이티브 상태 아이콘과 재사용하는 NSPopover 하나를 관리합니다. CPU·RAM 집계와 `/`의 statvfs만 10초마다 읽고, 프로세스 목록·파일 순회·추가 WebView·측정 이력은 생성하지 않습니다. 샘플러 하나와 최신 측정값 하나만 유지하고 메인 스레드 UI 갱신도 최대 한 건만 대기시킵니다. 종료 신호 또는 채널 해제 시 측정을 중단합니다.

창 닫기는 숨김, 패널의 열기와 Dock 클릭은 기존 창 복원, 종료/⌘Q는 기존 작업 종료 절차를 사용합니다. 아이콘 생성에 실패하면 창 닫기 동작을 가로채지 않습니다. 숫자 표시 설정은 NSUserDefaults에 저장하고 패널·설정 화면을 이벤트로 동기화합니다. 메인 창을 숨겨도 기존 상태/메모리는 유지됩니다. macOS 전용 코드이며 Windows 트레이는 그대로입니다.

## 명령

```powershell
npm install
npm run check
npm run test:all
npm run build
npm run prepare:sidecar
npm run tauri dev
npm run tauri build
```

Rust 워크스페이스 명령은 저장소 루트에서 실행합니다.

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

`prepare:sidecar`는 MCP와 문서 처리 도구를 모두 준비합니다. 8 GiB 환경에서는 Cargo 실행 시 `CARGO_BUILD_JOBS=1 CARGO_INCREMENTAL=0`으로 빌드 작업을 직렬화할 수 있습니다. 새 문서 도구 없이 배포하면 PDF·Office 재색인이 안전 오류로 중단됩니다.

## 안전 경계

- 일반 파일 작업은 검증된 후보의 운영체제 휴지통 이동입니다. 별도 시스템 휴지통 비우기와 Docker 정리만 명시적 영구 삭제 예외입니다. AI/CLI/MCP에는 휴지통 비우기 권한을 주지 않습니다.
- 문서 본문 색인은 로컬 앱 캐시에 저장합니다. 별도 허용한 MCP 문서 검색은 경로와 일치 문맥을 외부 클라이언트에 반환할 수 있습니다.
- 문서 색인은 공유 읽기 핸들·크기 상한·취소 가능한 트랜잭션을 사용하고 마지막 완료 색인을 보존합니다.
- 빠른 파일 찾기는 본문을 열지 않고 이름·경로·크기·수정 시각만 앱 캐시에 색인합니다.
- 파일 카탈로그도 취소 가능한 트랜잭션과 공용 단일 작업 잠금을 사용하며, 앱의 휴지통 이동 뒤에는 업데이트 전까지 검색을 잠급니다.
- 트리맵 분석·드릴다운과 빈 폴더 탐색은 읽기 전용입니다. 별도 더보기 메뉴의 개별 파일 휴지통 이동에는 파일 신원·경로 재검증과 최종 확인을 적용합니다.
- 알려진 클라우드 동기화 경로와 온라인 전용 항목은 순회 전에 제외하며, 인식된 클라우드 루트의 직접 검사도 거부합니다.
- macOS 앱 메모리 정리는 BroomSweepy 호스트 프로세스의 미사용 allocator 페이지만 반환하며 시스템 전체·다른 앱·WebView 보조 프로세스의 메모리는 건드리지 않습니다.
- 부분 해시는 후보 축소에만 사용합니다.
- 중복 결과는 전체 BLAKE3 해시와 바이트 비교까지 통과해야 합니다.
- 하드링크는 동일한 디스크 할당으로 계산해 회수 가능 용량에서 제외합니다.
- 중복 사진 필터도 바이트가 완전히 같은 파일만 포함하며 유사 사진으로 확대 해석하지 않습니다.
- 파일 더블클릭은 실행 파일과 스크립트를 실행하지 않고 탐색기에서 위치만 표시합니다.
- Temp는 7일, AppData는 90일의 변경 없음 근거를 요구하며 AppData는 항상 검토 대상으로 표시합니다.
- 제거 프로그램 레지스트리는 서로 다른 경로 증거가 둘 이상 끊긴 항목만 검토 대상으로 표시하고 변경하지 않습니다.
- 휴지통 이동은 서버 보고서 재검증, 그룹별 보관본, 작업 저널, 부분 실패 중단을 강제합니다.
- 앱 내부 자동 복원은 제공하지 않습니다. 일반 이동은 OS 휴지통에서 복원하며, 별도 휴지통 비우기를 실행하면 복원 수단이 사라집니다.

## 문서용 화면 재현

`npm run dev` 후 `http://127.0.0.1:1420/release-preview.html?view=dashboard&language=ko`를 엽니다.
`view`는 `dashboard`, `overview`, `performance`, `assistant`, `settings`를 지원하며 `language`는 `en`, `ko`, `ja`, `zh-CN`입니다.
실제 React 화면에 예시 데이터를 공급하는 개발 전용 진입점으로, 패키징된 앱에 포함되지 않으며 실제 파일·AI·OS 작업은 실행하지 않습니다.
캡처 규격은 [스크린샷 안내](../../docs/assets/screenshots/README.md)를 참고하세요.
